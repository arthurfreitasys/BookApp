# BookApp

Projeto de estudos desenvolvido durante as aulas de React, seguindo o código e o passo a passo disponibilizados pelo professor.

O objetivo é acompanhar o desenvolvimento de uma aplicação de livros e praticar os conceitos apresentados durante o aprendizado de React.

## Tecnologias

- React
- JavaScript
- Expo
- Supabase

## Objetivos de aprendizado

- Compreender a estrutura de um projeto React.
- Praticar a criação e organização de componentes.
- Entender o funcionamento da aplicação e seus serviços.
- Aprender a integrar o projeto com o Supabase.

## Como executar

Clone o repositório:

```bash
git clone https://github.com/arthurfreitasys/BookApp.git
```

Entre na pasta do projeto:

```bash
cd BookApp
```

Instale as dependências:

```bash
npm install
```

Configure as variáveis de ambiente necessárias para a conexão com o Supabase e execute o projeto conforme as instruções da aula.

Para executar a versão web:

```bash
npx expo start --web
```
